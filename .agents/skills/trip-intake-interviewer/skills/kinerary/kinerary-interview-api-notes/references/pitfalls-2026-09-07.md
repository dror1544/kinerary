# API pitfalls discovered 2026-09-07

## `record_answers_for_chat` — structured field is `data`, not `structured`

Using the field name `structured` for a structured question in the batch call
silently drops the answer. The rejection comes back in `rejected[]` with
`DATA_REQUIRED`. **Use `data`.**

Correct shape:
```json
{ "questionId": "phases", "data": [...] }
```
Wrong (silently rejected):
```json
{ "questionId": "phases", "structured": [...] }
```

Confirmed on `phases` question, 2026-09-07.

## `say_for_chat` returns 404 when `nextQuestion` is null — even mid-session

When `phases` is the last required question and you submit it, `nextQuestion`
becomes null immediately. The router closes the turn. Subsequent calls to
`say_for_chat` return `404 NOT_FOUND`. This is NOT a broken session — the
router re-opens a turn when the organizer writes next.

**Consequence:** interleave dietary, pace, and bot-name questions *before*
submitting `phases`. Once you submit phases and nextQuestion goes null, you
cannot send anything more until the next organizer message.

## PDF extraction: use `import fitz`, not `import pymupdf` or pdfminer

`pdfminer` is not reliably installed. `import pymupdf` may also fail.
`import fitz` is the reliable alias for pymupdf and works in all observed
environments. Pattern:

```python
import fitz
doc = fitz.open(path)
text = "".join(p.get_text() for p in doc)
```

## Multi-organizer session: always check tripId

When a different organizer starts a new interview in the same Telegram channel,
`get_interview_for_chat` returns a fresh state with a new `sessionId` and
`tripId`. The state reads as if the session just started (nextQuestion =
`destination`, empty selections). Do not carry over any mental state from the
prior organizer's interview. Always verify tripId at the start of each turn.

## Duplicate documents

Organizers sometimes resend the same document multiple times. If the content
is identical to a previously processed file, skip re-recording. The state read
will show which fields are already answered — trust that, not the document.
