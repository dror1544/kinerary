# Attraction ticket verification — family-trip pattern

Before answering questions about an uploaded attraction ticket:

1. Extract the PDF text (use PyMuPDF/pymupdf for text PDFs; use OCR only if needed).
2. Separate what the ticket explicitly states from what is merely typical practice.
3. Report the exact validity date, admission inclusion, benefit scope, operating-hours rule, ID requirement, parking inclusion, and exclusions.
4. If the ticket says “valid during normal operating hours” but does not print an opening time, do not invent a time. Check the official calendar or state that the PDF does not specify the exact hour.
5. For minors without photo ID, do not infer an exception. Say the ticket requires photo ID and the document gives no minor exception; recommend contacting Guest Services. If a passport is available, an adult can securely carry the original to the gate—do not tell the child to carry it all day.
6. Do not claim a photo/photocopy is accepted unless the official source confirms it.
7. Distinguish an Express benefit from Early Access: Express reduces waits during normal operating hours; Early Access is a separate product unless the ticket explicitly includes it.

Example from Universal Express Unlimited: the ticket explicitly included 1-Day General Admission plus unlimited-per-day Express access to each ride, attraction, and seated show; it stated normal operating hours, required valid photo ID, excluded parking, and did not print the actual opening hour.
