# San Francisco split-day and snack sequencing example

Use case: user wanted a low-stress Monday in San Francisco after deciding to skip Muir Woods, and preferred:
- 08:00 hotel departure
- morning cafe stop
- Pier 39 / sea lions
- Lombard Street
- Chinatown later in the day because the goal was stalls, bakeries, and nibbling without getting too full earlier
- a hard optional split around 15:00 so grandparents or tired travelers could return to the hotel
- everyone to reconverge at the hotel, shower/change, and then leave together for a 19:30 dinner

## Planning pattern

1. Put the visually bigger / more energetic stop first:
   - Pier 39 in the morning
2. Add the nearby iconic stop next:
   - Lombard Street
3. Move the snack-oriented neighborhood later:
   - Chinatown as a 13:45-15:00 browse/nibble block rather than a morning anchor
4. Create a split point:
   - 15:00 everyone together until here
   - Branch A: hotel rest
   - Branch B: low-logistics continuation in North Beach / Washington Square Park
5. Set a firm reconvergence time:
   - latest comfortable hotel return for the late branch: 17:30 if dinner is at 19:30 and showers/changing matter
6. Leave for dinner together after the reset block.

## Why this pattern worked

- matched the user's food logic (snacks later, not earlier)
- supported mixed energy levels in a 7-person family group
- avoided forcing everyone through one continuous day
- preserved a shared evening start even though the afternoon split

## North Beach / Washington Square guidance

This is a good "continue if you still have energy" branch because it is:
- pleasant but not demanding
- close to dinner options
- suitable for coffee, dessert, short strolling, and sitting
- easy to cut short if the group is getting tired

Use it as a soft continuation, not as another must-do attraction.
