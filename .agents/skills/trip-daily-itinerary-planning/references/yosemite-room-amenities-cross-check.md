# Yosemite View Lodge room amenities cross-check

Use this as a concrete example for quick lodging-amenity questions during the trip.

## Question class
- "Are there refrigerators in the rooms?"
- "Can we store milk/tuna/vegetables?"
- "Does this hotel have a microwave / kitchenette?"

## Working pattern
1. Check the booked hotel from the trip plan / site booking first so you verify the right property.
2. Check the hotel website for room descriptions and amenities.
3. If the hotel site suggests the amenity exists but looks room-type-specific, cross-check with a secondary booking-style source (for example Booking listing or National Park Reservations room-details page).
4. Answer briefly and distinguish between:
   - confirmed common amenity: "there is a mini-fridge / microwave"
   - partial amenity: "some room types also have a kitchenette"
   - not guaranteed for every room: say so explicitly if you do not have the exact booked room type
5. For food-planning follow-ups, translate the amenity into practical guidance:
   - milk / tuna / vegetables = fine with mini-fridge + microwave
   - full cooking = only if kitchenette/stove is actually confirmed

## Grounded result from this session
For Yosemite View Lodge:
- Hotel room pages showed refrigerators and several kitchenette-equipped room types.
- National Park Reservations room-details page explicitly listed **Microwave** and **Mini-Refrigerator** in room amenities and noted that many rooms offer kitchenettes.

## Answer shape that worked
- "כן — לפי אתר המלון וגם דפי ההזמנה יש מיני-מקרר ומיקרוגל, ובחלק מהחדרים גם kitchenette."
- Then one short practical line: "לחלב, טונה וירקות זה אמור להיות מצוין."

## Pitfall
Do not overstate "every room has a kitchenette" unless the exact booked room type is verified.
