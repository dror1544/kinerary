# Yosemite follow-up after a Mist Trail morning

Use this when the family already did the big Glacier Point / Valley View / Mariposa day and the next day should center on a shorter Yosemite Valley hike.

## Recommended structure

- Primary anchor: **Mist Trail to the Vernal Fall footbridge**
- Then prefer **nearby low-logistics valley stops** instead of another long drive
- Best follow-ups:
  - **Mirror Lake** — same general Curry Village / Happy Isles zone, light add-on
  - **Yosemite Village** — reset stop for food, water, bathrooms, store, short wander
  - optional **Valley View / Yosemite Valley** — easy scenic add-on if energy remains

## Distances / timing pattern used in this session

Grounded route checks from Yosemite View Lodge / Happy Isles / Mirror Lake / Yosemite Village / Valley View:
- Yosemite View Lodge → Happy Isles: about **37 min drive**
- Happy Isles → Mirror Lake: about **7 min drive**
- Mirror Lake → Yosemite Village: about **9 min drive**
- Yosemite Village → Valley View: about **13–14 min drive**
- Yosemite Village → Yosemite View Lodge: about **30 min drive**

## Official Mist Trail footbridge correction

Ground this section in the official NPS page:
- `https://www.nps.gov/yose/planyourvisit/vernalnevadatrail.htm`

Official NPS trail overview for the short version:
- **Vernal Fall Footbridge**
  - Distance: **1.6 mi (2.6 km) round trip**
  - Elevation gain: **400 ft (120 m)**
  - Difficulty: **Moderate**
  - Time: **1–1.5 hours**
- The footbridge viewpoint itself is at **0.8 mi / 1.3 km one way**.

Important correction from this session:
- The trip note shorthand `3 ק"מ לגשר` is easy to misread.
- Do **not** expand it into **6 km round trip** without official confirmation.

## Hike timing guidance

For **Mist Trail to the footbridge and back**:
- treat as **2.6 km round trip**, not 6 km
- with one adult + kids and no grandparents, a realistic block is about **1.5–2 hours** depending on stops and pace
- start around **07:45–08:00** when possible

## Framing guidance

- Do **not** sell Yosemite Village as a major attraction; describe it as a **useful reset stop** after the hike
- If the user asks whether **Tenaya Lake** is realistic after Mist Trail, default answer is usually **no for a low-stress day** because it adds major driving after the hike
- Explain Mirror Lake as **very close to Mist Trail / Happy Isles**, not as a separate distant destination
- If the user asks to "add Yosemite Valley if it's close," the right move is usually to add **Valley View** after Yosemite Village rather than rebuilding the whole day

## One-link route pattern

For low-signal park days, provide one Google Maps route:
- hotel → Happy Isles / Mist Trail
- Mirror Lake
- Yosemite Village
- optional Valley View
- hotel

And mention offline maps briefly.
